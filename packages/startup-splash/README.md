# Startup Splash — DeepSeek Harness 启动加载动画

一个 Harness Web 界面插件：页面每次启动时，先播放一段铺满整个视口的"超空间启动"序列，然后爆闪淡出，把界面交还给应用。

## 效果

整屏都在动，而不是只有中间一小块：

1. **曲速星场**：全屏 Canvas 上约 150–280 条从中心向外加速的拖尾光线，越靠外越快、越亮，最后 0.6 秒进入"跃迁加速"；零散亮点偶尔闪一下；
2. **极光色场**：三团巨大的径向渐变光晕（蓝 / 紫 / 青）在屏幕四角缓慢漂移、缩放，用 screen 混合叠在星场上；
3. **旋转光束**：覆盖全屏的锥形光束缓慢旋转，像探照灯扫过；
4. **全屏扩散环**：三道直径 140vmax 的圆环依次从中心扩散到屏幕之外，循环无缝衔接；
5. **HUD 框架**：四角取景框、视口内发光边框、点阵网格、纵向暗角、自上而下的扫描光带；
6. **中心锚点**：一颗脉动能量核心（三层反向旋转的锥形光弧 + 发光圆点），下方是乱码解码的「DEEPSEEK // HARNESS」字标与实时启动读数（阶段文案 + 百分比 + 发光头部进度条）；
7. **退场**：全屏轻微放大、扩散光环 + 闪白，700ms 淡出并卸载。

- 点击任意位置、点击「点击任意位置跳过」按钮或按 `Esc` 可立即跳过。
- 跟随系统「减少动态效果」设置：星场静止、极光/旋转/扫描关闭，约 0.7 秒后淡出。
- 背景、文字、边框使用 `--dsw-alias-*` 主题变量，自动适配明暗主题；光效使用自有配色。
- 文案通过 Harness 语言服务提供英文与简体中文两套。

## 技术说明

- 只有**一个** Canvas，每帧只画普通线段与少量圆点，没有逐面光照、排序或大滤镜，避免 3D 网格版本的开销；
- 其余效果全部是 CSS transform / opacity 动画，由合成器完成；
- 星场按视口尺寸自适应粒子数量，窗口缩放时重建；
- 样式、`requestAnimationFrame`、定时器都由组件生命周期持有，卸载即清理。

## 安装后位置

注册在 `shell.overlay`（框架级浮层，`order: 1000`），显示期间会暂时挡住应用交互，淡出后完全卸载。

## 文件

| 文件 | 作用 |
|---|---|
| `package.json` | 包清单：`dsh.bundle.patch`、`dsh.client`（`immediately: true`）、导出与图标 |
| `cordis.patch.yml` | Loader 行：插入 `startup-splash` 条目 |
| `index.js` | Host 半侧：仅提供加载行，无 Host 服务 |
| `client.js` | Client 半侧：`shell.overlay` 注册、全屏星场、光效层与全部动画 |
| `locale/en.json`、`locale/zh.json` | 插件管理器显示标题/描述 |
| `icon.svg` | 插件图标 |

## 卸载

在设置 → 插件中禁用或移除 `Startup Splash` 即可。
